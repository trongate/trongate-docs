get_user_obj()

public function get_user_obj(?string $token = null): object|bool

Description

Retrieves the full user object associated with a token. If no token is provided, checks session, cookie, and HTTP headers automatically.

The user object contains all columns from the user record (typically from trongate_users or your custom users table).

Parameters

Parameter Type Description Default Required
$token string|null A 32‑character alphanumeric token. If null, the method searches the cookie, then the session, then the HTTP header. null No

Return Value

Type Description
object|bool
  • object – User record as a standard object (properties correspond to table columns)
  • false – Token not found or invalid

Example Usage

[code=php] // Get current user object $user = $this->trongate_tokens->get_user_obj(); if ($user !== false) { echo "Welcome, " . $user->username; echo "Email: " . $user->email; } // Get user object from specific token $token = post('token', true); $user = $this->trongate_tokens->get_user_obj($token); // Use in member area controller // attempt_get_valid_token() checks expiry_date; get_user_obj() does not. public function dashboard() { if ($this->trongate_tokens->attempt_get_valid_token() === false) { redirect('members/login'); } $data['user'] = $this->trongate_tokens->get_user_obj(); $this->view('dashboard', $data); } // API endpoint returning user profile // No password column is returned, so the object can be encoded as it stands. public function me() { if ($this->trongate_tokens->attempt_get_valid_token() === false) { http_response_code(401); echo json_encode(['error' => 'Unauthorized']); die(); } echo json_encode($this->trongate_tokens->get_user_obj()); }[/code]

Notes

  • Calls $this->model->get_user_obj($token).
  • This method does not check expiry_date. Use attempt_get_valid_token() when the result has to be expiry‑checked.
  • Token search order when $token is null: cookie → session → HTTP header.
  • The object contains six properties: trongate_user_code, user_level_id, user_level, token, trongate_user_id and expiry_date. No password column is included.
  • Returns false when no stored token matches.
  • The query reads trongate_tokens joined to trongate_users and trongate_user_levels. Those table names are fixed in the model.
