get_user_level()

public function get_user_level(?string $token = null): string|bool

Description

Retrieves the user level (title) associated with a token. If no token is provided, checks session, cookie, and HTTP headers automatically.

User levels are string titles from trongate_user_levels.level_title, reached through trongate_users.user_level_id (e.g., 'admin', 'member', 'guest').

Parameters

Parameter Type Description Default Required
$token string|null A 32‑character alphanumeric token. If null, the method searches the cookie, then the session, then the HTTP header. null No

Return Value

Type Description
string|bool
  • string – User level title (e.g., 'admin', 'member', 'guest')
  • false – Token not found or invalid

Example Usage

[code=php] // Get current user's level $level = $this->trongate_tokens->get_user_level(); if ($level !== false) { echo "User level: " . $level; } // Check if user is admin // attempt_get_valid_token() checks expiry_date; get_user_level() does not. public function admin_area() { if ($this->trongate_tokens->attempt_get_valid_token() === false) { redirect('members/login'); } if ($this->trongate_tokens->get_user_level() !== 'admin') { redirect('members/not_allowed'); } // Show admin content... } // Role‑based access control public function edit_post(int $post_id) { $token = $this->trongate_tokens->attempt_get_valid_token(); if ($token === false) { redirect('members/login'); } $level = $this->trongate_tokens->get_user_level($token); $user_id = $this->trongate_tokens->get_user_id($token); $post = $this->model->get_post($post_id); if ($level === 'admin' || ($level === 'editor' && $post->author_id === $user_id)) { // Allow edit } else { redirect('posts/view/' . $post_id); } } // API endpoint for admins only public function delete_user(int $user_id) { $token = $this->trongate_tokens->attempt_get_valid_token(); if ($token === false || $this->trongate_tokens->get_user_level($token) !== 'admin') { http_response_code(403); echo json_encode(['error' => 'Forbidden']); die(); } // Delete user... }[/code]

Notes

  • Internally calls get_user_obj() to retrieve the full user object, then extracts the user_level property.
  • Token search order when $token is null: cookie → session → HTTP header.
  • This method does not check expiry_date. Use attempt_get_valid_token() when the result has to be expiry‑checked.
  • Returns false when no stored token matches.
  • User level is a string; for integer‑based levels, you may need to cast or use a different approach.
  • The user_level value comes from trongate_user_levels.level_title, joined through trongate_users.user_level_id.
